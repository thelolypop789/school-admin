# ระบบจัดการงานบริหารทั่วไป · โรงเรียนวังหลวงพิทยาสรรพ์

โมดูลหลัก:
1. **จองห้องประชุม** — ปฏิทินรายวัน, จองทันที, กันจองซ้อนที่ระดับฐานข้อมูล
2. **จองรถ** — ส่งคำขอ → หัวหน้างานยานพาหนะจัดรถ/คนขับ → รอง ผอ. ฝ่ายบริหารทั่วไปเห็นชอบ → ผอ. อนุมัติ → พิมพ์คำสั่งโรงเรียน เรื่อง การอนุมัติการเดินทางไปราชการ ตามแบบของโรงเรียน (ผอ. เซ็นสด, เลขที่คำสั่งเว้นให้สารบรรณกรอก); ขั้นไหนไม่เห็นชอบส่งกลับขั้นก่อนหน้าพร้อมเหตุผล (ผอ. ไม่อนุมัติแบบยุติเรื่องได้); หลังอนุมัติ เจ้าหน้าที่ยานพาหนะบันทึกออกเดินทาง (เลขไมล์ + checklist) และปิดงาน (เลขไมล์กลับ + น้ำมัน) → สรุปการใช้รถ/ค่าน้ำมันรายเดือน + CSV; ตารางรถ, กันรถ/คนขับซ้อน, ไม่ให้จัดคนขับที่ใบขับขี่หมดอายุ, เตือนยื่นล่วงหน้าน้อยกว่า 3 วัน, ขอเพิ่มอีกคันจากคำขอเดิม
3. **สุขาดี มีความสุข** — QR ติดหน้าห้องน้ำ → สแกนแล้วตรวจตาม checklist HAS (สะอาด/เพียงพอ/ปลอดภัย) + รูป, dashboard สถานะวันนี้, รายงานข้อที่ไม่ผ่านบ่อย, ส่งออก CSV
5. **นศท.** — นักเรียนเข้า `/s` ด้วยรหัสนักเรียน + PIN (ครั้งแรกยืนยันด้วยเลขบัตรประชาชน) รายงานตัวเช้าวันพุธ/คาบกิจกรรม และเวรจราจรด้วยเซลฟี่ + พิกัด; ครูผู้กำกับนำเข้ารายชื่อจาก Excel/Sheets ตั้งคาบ จัดเวรจราจรอัตโนมัติตามกลุ่ม อนุมัติแลกเวร ดูสรุป/CSV
4. **เขตทำความสะอาด** — แผนที่ 3 มิติของโรงเรียนระบายสีทุกเขตตามสถานะวันนี้; ครูที่ปรึกษาถ่ายรูปรายงานเขตของตัวเองทุกวันที่มีเรียน → เจ้าหน้าที่อาคารสถานที่ยืนยันผล (สะอาด/พอใช้/ต้องปรับปรุง) หรือสุ่มตรวจ → ต้องปรับปรุงแจ้งครูทาง LINE; สรุปคะแนน 30 วันรายเขต; หัวหน้างานอาคารฯ วาดเขต/ผูกครูที่ปรึกษาในแผนที่ได้

เป็น PWA: เปิดในมือถือแล้ว "เพิ่มไปยังหน้าจอหลัก" ได้ (Android: เมนู ⋮ → ติดตั้งแอป, iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม)

Stack: React 19 + TypeScript + Vite, Supabase (Auth Google / Postgres + RLS / Storage), Vercel

## ติดตั้งครั้งแรก

### 1. ฐานข้อมูล (Supabase)
1. Supabase → project `school-admin` → **SQL Editor** → New query
2. วางเนื้อหาไฟล์ใน `supabase/migrations/` ทีละไฟล์ตามลำดับชื่อ → **Run** ทีละไฟล์
   - `20261109000000_init.sql` — ตาราง, RLS, ฟังก์ชัน, bucket รูป `toilet-photos`, checklist ตั้งต้น 15 ข้อ
   - `20261111000000_vehicle_approval_chain.sql` — จองรถอนุมัติ 3 ขั้น + บทบาทใหม่ (approver เดิมกลายเป็น รอง ผอ.)
   - `20261112000000_travel_order_fields.sql` — ตำแหน่งบุคลากร, รายชื่อผู้เดินทาง, รายการเบิก (ใช้พิมพ์คำสั่งไปราชการ)
   - `20261119000000_vehicle_trip_log.sql` — บันทึกเดินทาง/ปิดงาน (เลขไมล์ น้ำมัน), วันหมดอายุใบขับขี่, ผอ. ไม่อนุมัติแบบยุติเรื่อง
   - `20261119000001_harden_function_privileges.sql` — ปิดสิทธิ์เรียก trigger function ผ่าน RPC, ตั้ง search_path
   - `20261120000000_line_approval.sql` — อนุมัติ/ส่งกลับ/ไม่อนุมัติผ่าน LINE, ผูก LINE ด้วยรหัส, trigger แจ้งเตือน (ต้องตั้ง `private.config` และ deploy `line-bot`)
   - `20261121000000_vehicle_fleet.sql` — รูปรถ (bucket `vehicle-photos`), สภาพรถ, วันหมดอายุประกันภัย/พ.ร.บ./ภาษี; จัดรถที่ซ่อมหรือ พ.ร.บ./ภาษีหมดไม่ได้
   - `20261122000000_toilet_reports_readonly.sql` — บุคลากรทั่วไปดูรายงานห้องน้ำได้อย่างเดียว (ตรวจ/ดูรูปเฉพาะฝ่ายบริหารทั่วไป)
   - `20261123000000_multi_roles.sql` — คนเดียวถือหลายบทบาท (บทบาทเสริม), เพิ่มหัวหน้างานอาคารสถานที่ / หัวหน้าฝ่ายบริหารทั่วไป
   - `20261124000000_repairs.sql` — แจ้งซ่อมอาคารสถานที่ (ตาราง `repair_requests`/`repair_steps`, bucket `repair-photos`, RPC `repair_*`, trigger แจ้งเตือน LINE)
   - `20261125000000_ga_calendar.sql` — ปฏิทินงานฝ่ายบริหารทั่วไป (ตาราง `ga_events`, RPC `ga_event_save`/`ga_event_delete`)
   - `20261126000000_clean_zones.sql` — เขตทำความสะอาด (ตาราง `clean_zones`/`clean_reports`, bucket `clean-photos`, RPC `clean_submit`/`clean_verify`/`clean_zone_save`, trigger แจ้งเตือน LINE เมื่อต้องปรับปรุง)
   - `20261126000100_clean_zones_seed.sql` — เขตเริ่มต้น 23 เขต (ม.1/1–ม.6/3) ไม่มีชื่อครู — ใส่ชื่อ/ผูกบัญชีครูในแอป (แท็บเขตทำความสะอาด → ตั้งค่าเขตนี้)
   - `20261128000000_nst.sql` — นศท. (นักเรียน/คาบเช็คชื่อ/เวรจราจร/แลกเวร, bucket `nst-photos`, บทบาท `nst_teacher`) ต้อง deploy edge function `nst-auth` (verify_jwt = false) และเปิด Email provider ใน Supabase Auth (ใช้ออก session ให้นักเรียน ไม่มีการส่งอีเมล)
   - `20261128000100_nst_purge_cron.sql` — pg_cron ลบรูปหลักฐาน นศท. ที่เก่ากว่า 30 วันทุกคืน
3. `pongsarkon@wangluangpitt.ac.th` จะเป็น admin อัตโนมัติเมื่อล็อกอินครั้งแรก

### 2. ล็อกอิน Google
1. Google Cloud Console → APIs & Services → Credentials → OAuth client (ใช้ของ FormAuto เดิมได้)
   → **Authorized redirect URIs** เพิ่ม `https://rvoixpbaiwilpigcxeix.supabase.co/auth/v1/callback`
2. Supabase → Authentication → Sign In / Providers → **Google** → เปิด แล้ววาง Client ID + Client Secret
3. Supabase → Authentication → URL Configuration
   - Site URL: โดเมนจริง เช่น `https://admin.wangluangpitt.ac.th`
   - Redirect URLs: `https://admin.wangluangpitt.ac.th/**`, `https://<project>.vercel.app/**`, `http://localhost:5174/**`

### 3. Vercel
1. Add New → Project → Import `school-admin` (Framework: Vite)
2. Environment Variables:
   - `VITE_SUPABASE_URL` = `https://rvoixpbaiwilpigcxeix.supabase.co`
   - `VITE_SUPABASE_KEY` = Supabase → Project Settings → API Keys → **anon / publishable** key (ห้ามใช้ service_role)
3. Deploy (แก้ env แล้วต้อง Redeploy เพราะค่าฝังตอน build)
4. โดเมน: Settings → Domains → เพิ่ม `admin.wangluangpitt.ac.th` → ให้ผู้ดูแลโดเมนโรงเรียนเพิ่ม CNAME ตามที่ Vercel บอก

### 4. ตั้งค่าในแอป (เมนู "จัดการ")
1. เพิ่มห้องประชุม, รถ, คนขับ, จุดห้องน้ำ
2. ห้องน้ำ + QR → **พิมพ์ QR ทุกจุด** (A4 ได้หลายจุด) → ติดหน้าห้องน้ำ
3. ให้ครูล็อกอินครั้งแรก แล้วตั้งชื่อ-นามสกุล (มีคำนำหน้า) และตำแหน่งของตัวเอง (กดชื่อมุมขวาบน หรือลิงก์ใต้คำทักทายในหน้าแรก) — ชื่อ ผอ. จะพิมพ์ใต้ช่องลงนามในคำสั่ง
4. ผู้ดูแลระบบตั้งบทบาทในแท็บ "ผู้ใช้"
   - **หัวหน้างานยานพาหนะ**: จัดรถ/คนขับ แล้วส่งต่อ (ขั้นที่ 1)
   - **รอง ผอ. ฝ่ายบริหารทั่วไป**: เห็นชอบคำขอรถ (ขั้นที่ 2), ดูรายงานห้องน้ำ
   - **ผู้อำนวยการ**: อนุมัติคำขอรถ (ขั้นสุดท้าย), ดูรายงานห้องน้ำ
   - **เจ้าหน้าที่อาคารสถานที่** (`inspector`): ตรวจห้องน้ำ + ยืนยันผลเขตทำความสะอาด (ต้องมีอีเมลโรงเรียน)
   - **ผู้ดูแลระบบ**: ทำได้ทุกอย่าง
